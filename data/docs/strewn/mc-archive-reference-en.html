Archive Contents

The MC archive records the setup and results of orbital Monte Carlo, together with entry states for subsequent atmospheric simulation. Each run directory represents one orbital run. Atmospheric realizations, breakups and impacts are stored in a separate result directory. 

MC/
  run-<id>/
    request.json
    result.json
    entries.json
    manifest.json
    handoff.json
    atmosphere.json

request, result, entries, handoff and manifest are created by the orbital exporter. atmosphere is added during atmospheric job preparation; it may not yet exist immediately after a purely orbital export.

File Purpose
request.json Initial conditions and settings of the orbital Monte Carlo calculation.
result.json Numerical orbital MC result: counters and boundary crossings.
entries.json Ready-to-use atmospheric entry states in SI units.
manifest.json Orbital calculation status and readiness for the next stage.
handoff.json Entry-state handoff description for external consumers.
atmosphere.json Editable job configuration for the next atmospheric Monte Carlo run.

request.json

Initial conditions and settings of the orbital Monte Carlo calculation.

Contains the nominal state, full covariance, sampling settings and propagation settings.

General

Field Type and Allowed Values Description
schema_version integer: 1 Request schema version, not the application version.
object string Object designation, used for identification and the report title.
sampling_kind state_covariance | parameter_covariance Sampling source: six state components, or the state together with fitted nongravitational parameters. The latter also has dimension 6 when no nongravitational parameters are fitted.
external_ephemerides_embedded boolean: false External ephemerides are not embedded in these JSON files. They are required separately to repeat orbital propagation.

nominal: nominal state

Field Type and Allowed Values Description
nominal.frame string: heliocentric ECLM J2000 Heliocentric J2000 ecliptic frame. Specifies the origin and orientation of the state vectors.
nominal.epoch_mjd_tdb number; MJD TDB State epoch. JD = MJD + 2400000.5; TDB must not be interpreted as UTC.
nominal.position_au number[3]; AU Position [x,y,z] at the stated epoch.
nominal.velocity_au_day number[3]; AU/day Velocity [vx,vy,vz]. Conversion from internal velocity units has already been applied.

covariance: uncertainty

Field Type and Allowed Values Description
covariance.matrix number[n][n]; n = 6 ... 10 Full covariance matrix, including correlations. Diagonal entries are variances, not standard deviations. Each Cij has the product of the units of parameters i and j.
covariance.parameter_order string[n] Row and column order: x_au, y_au, z_au, vx_au_day, vy_au_day, vz_au_day, followed by selected a1_au_day2, a2_au_day2, a3_au_day2 and dt_day.
covariance.objective_scale_already_applied number > 0 Covariance multiplier already applied before MC. Standard deviations scale by its square root. Do not apply it to matrix again.
covariance.additional_scale number: 1 Provenance field: the current exporter writes 1. It is not a separate sampler control.
covariance.valid boolean Validation of dimensions, finite values, positive diagonal, symmetry and spectrum. Asymmetry tolerance: 1e-10 times the matrix norm; minimum allowed correlation-matrix eigenvalue: -1e-10.

non_grav: nongravitational model

Field Type and Allowed Values Description
non_grav.enabled boolean Whether nongravitational acceleration is enabled.
non_grav.model integer: 0 ... 4 0: None; 1: MarsdenH2O; 2: MarsdenCO; 3: InverseSquare; 4: Yarkovsky (A2).
non_grav.fit_mask integer; bit mask Fitted parameters: A1=1, A2=2, A3=4, DT=8; combine bits as needed. Zero means no fitted NG parameters. Allowed bits depend on the model; fixed coefficients need not be included.
non_grav.a1_au_day2 number; AU/day^2 Nominal radial coefficient A1.
non_grav.a2_au_day2 number; AU/day^2 Nominal transverse coefficient A2.
non_grav.a3_au_day2 number; AU/day^2 Nominal coefficient A3 normal to the orbital plane.
non_grav.dt_day number; day Time shift in the activity law for models that support it. Not a correction to observation epochs.

monte_carlo: orbital sampling

Field Type and Allowed Values Description
monte_carlo.clones integer > 0 Requested number of orbital clones. Not the number of atmospheric realizations or fragments.
monte_carlo.seed uint64 Clone-generation seed. Preserve integer precision; reproduction also requires the same RNG algorithm.
monte_carlo.rng string Algorithm identifier: SplitMix64 keyed Box-Muller; clone ID and parameter index. Describes deterministic random-number keys for each clone and parameter.
monte_carlo.altitude_km number >= 0; km Orbital stopping boundary. A positive value specifies geodetic altitude; zero preserves the legacy spherical boundary. The UI atmospheric handoff requires 100 km.
monte_carlo.noise_sigma_mult number Sampling standard-deviation multiplier in the general API: positive values scale the covariance factor; nonpositive values are treated as 1. The UI uses 1. Distinct from scaling already applied to matrix.
monte_carlo.noise_sigma_mult_applies boolean: false The current exporter always writes false; this is not a sampler control.
monte_carlo.openmp_max_threads integer >= 1 OpenMP maximum thread count at export time, not a measured concurrency count. Builds without OpenMP write 1.

propagation: dynamics and events

Field Type and Allowed Values Description
propagation.integrator RA15 | IAS15 Selected orbital integrator.
propagation.accuracy number > 0 Accuracy parameter of the selected integrator. Not a position error in metres; RA15 and IAS15 use different criteria.
propagation.step_days number; day Initial orbital integration step. Internal steps are adaptive; this is not an output interval or maximum step.
propagation.planet_mask integer; bit mask Bits 0–7: Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, Neptune; 8–10: Ceres, Pallas, Vesta in the fallback Keplerian model; 11: Moon. This mask does not disable the Sun. Available SB441 asteroids are enabled separately.
propagation.sb441 boolean With true and an available SPK source, all 16 SB441-N16 asteroids are used independently of bits 8–10. Otherwise the masked fallback trio is used. Ephemeris files are not embedded here.
propagation.encounter_points integer Step-refinement setting near encounters. Not a clone count or impact count.
propagation.earth_encounter_radius_au number > 0; AU Earth encounter neighbourhood radius used for step control. Not the Earth radius or entry altitude.
propagation.inactive_interior_mass_policy integer: 0 | 1 0: ExplicitOnly, explicitly enabled perturbations only. 1: SmoothCentralMass, smooth inclusion of disabled interior-planet masses in the central mass.
propagation.event_window_days number: 1; day Half-width of the crossing association window around a nominal event: plus or minus one day.
propagation.events object[] Nominal close approaches. Array order defines event indices in result.json and the order of hits_per_event.
propagation.events[].planet integer: 0 ... 8 Body identifier, not a bit mask: 0 Mercury, 1 Venus, 2 Earth, 3 Mars, 4 Jupiter, 5 Saturn, 6 Uranus, 7 Neptune, 8 Moon.
propagation.events[].epoch_mjd_tdb number; MJD TDB Nominal encounter epoch, not an individual clone entry time.
propagation.events[].distance_au number >= 0; AU Distance from the object to the target body centre at the nominal event, not altitude above its surface.
propagation.events[].position_au number[3]; AU Heliocentric object position at the event, in the J2000 axes of orbital propagation.
propagation.events[].velocity_au_day number[3]; AU/day Heliocentric object velocity in the same axes.
propagation.events[].planet_position_au number[3]; AU Heliocentric target-body position at the same epoch. Subtract positions to obtain the relative vector.
propagation.events[].planet_velocity_au_day number[3]; AU/day Heliocentric target-body velocity. Subtract velocities to obtain the relative inertial velocity.

physical: photometry

Field Type and Allowed Values Description
physical.absolute_magnitude number | null Absolute magnitude H. Null means no estimate; this is not apparent brightness. Used to infer size from H and albedo.
physical.albedo number | null; 0 < p <= 1 Albedo recorded in the orbital archive. A valid number is required for general handoff readiness. Atmospheric MC uses its own albedo distribution from atmosphere.json.

result.json

Numerical orbital MC result: counters and boundary crossings.

crossings contains confirmed crossings only, not all initial clones or step-by-step trajectories. A successfully propagated clone need not cross the boundary. The probability describes the selected boundary, not meteorite survival on the ground.

Summary

Field Type and Allowed Values Description
schema_version integer: 1 Result schema version.
altitude_km number >= 0; km Boundary represented by the records. Corresponds to request.monte_carlo.altitude_km.
attempted integer >= 0 In covariance MC, initialized to the requested clone count. After cancellation, it is not an exact count of attempts actually started.
completed integer >= 0 Successfully propagated clones, including those with no crossing. Denominator of the empirical probability.
failed integer >= 0 Clones with propagation or processing failures. Do not count them as physical misses.
cancelled boolean Whether the calculation was cancelled. A true value may accompany partial results.
any_crossing_clones integer >= 0 Number of distinct clones with at least one crossing among the selected events.
hits_per_event integer[] Crossing counts for each event in request.propagation.events order. The sum may exceed any_crossing_clones.
empirical_crossing_probability number; 0 ... 1 any_crossing_clones/completed when completed>0; otherwise 0. A value of 1 does not guarantee surviving fragments on the ground.
crossings object[] Boundary crossings. May be empty, partial, or include multiple events for one clone.

crossings[]: crossing record

Field Type and Allowed Values Description
crossings[].clone integer; 0 ... clones-1 Clone index in the generator. Do not substitute the array row index.
crossings[].event integer; 0 ... events.length-1 Index into request.propagation.events.
crossings[].planet integer: 0 ... 8 Target body; the same enum as request.propagation.events[].planet.
crossings[].epoch_mjd_tdb number; MJD TDB Refined crossing epoch in the orbital time scale.
crossings[].epoch_mjd_utc number; MJD UTC The same instant in UTC, used by the atmospheric stage and weather selection.
crossings[].body_fixed_valid boolean Whether body-fixed coordinates were obtained. False blocks atmospheric entry readiness.
crossings[].position_body_fixed_km number[3]; km Body-centred position [x,y,z] in rotating axes. For Earth, the exported ECEF transformation model applies.
crossings[].velocity_body_fixed_km_s number[3]; km/s Coordinate derivative in rotating axes, including frame rotation. Multiplied by 1000 for entries.
crossings[].latitude_deg number; degree Latitude derived from position. Geodetic WGS84 for Earth; the corresponding ellipsoid or sphere for other bodies.
crossings[].longitude_deg number; degree Body-fixed longitude, east-positive, approximately in [-180,180].
crossings[].relative_speed_km_s number >= 0; km/s Inertial speed relative to the target body. Not air-relative speed and not necessarily the norm of the body-fixed velocity.
crossings[].diagnostic_miss_km number | null; km Local two-body estimate of pericentre distance from the body centre. Not a surface miss distance or the crossing criterion. Null represents a nonfinite estimate.

entries.json

Ready-to-use atmospheric entry states in SI units.

Used with input.kind=state_samples. The UI accepts a complete set of unique inbound Earth states at 100 km for one event. Exported orbital entries have equal weights; no weight field is written. Partial duplication of result.json is intentional: the atmospheric module reads a self-contained entry format.

Dataset metadata

Field Type and Allowed Values Description
schema_version integer: 1 Entry-state schema version.
frame string: ECEF Position and velocity use geocentric rotating axes, not inertial axes.
frame_model string Transformation provenance captured when MC is calculated. Identifies the applied chain, polar motion and EOP profile separately. The current path uses IAU1976/1980, IAU1982 UT1/GAST, finals2000A with UTC fallback, and no polar motion. External results without provenance are labelled unknown (not recorded).
altitude_km number >= 0; km Orbital boundary altitude. The UI requires 100; each position is also checked against this height within 1 m.
boundary WGS84 geodetic height | legacy sphere Stopping-surface definition: geodetic height when altitude_km>0, legacy sphere when it is zero.
entries object[] Entry states. Completeness is checked against the requested orbital clone count.

entries[]: one state

Field Type and Allowed Values Description
entries[].id uint64 Unique entry key: cloneIndex × event count + eventIndex. Equals the clone index for one event. Referenced by atmospheric realization entry_id.
entries[].epoch_mjd_utc number; MJD UTC Entry time. Preserve float64 precision; conversion to rounded JD can lose precision.
entries[].position_ecef_m number[3]; m Position [x,y,z]. Corresponds to result position_body_fixed_km multiplied by 1000.
entries[].velocity_ecef_mps number[3]; m/s Velocity [vx,vy,vz] in rotating axes; wind has not yet been subtracted.

manifest.json

Orbital calculation status and readiness for the next stage.

Written last among the five orbital export files. A complete status alone does not imply a valid atmospheric handoff: readiness flags must also be checked. UI preparation checks schema_version, status and entry_states_ready.

Status fields

Field Type and Allowed Values Description
schema_version integer: 1 Manifest schema version.
status complete | partial | cancelled cancelled after cancellation; otherwise partial if failures occurred or the completed count is incomplete; otherwise complete. This exporter does not write running or failed.
entry_states_ready boolean Covariance, completeness, identifier, geometry and inbound-state checks passed. Availability of H/albedo is not included in this flag.
atmospheric_input_ready boolean General readiness: valid entries plus finite H and albedo 0<p≤1. The UI checks H separately and uses its own albedo distribution.
automatic_launch boolean: false Writing the archive does not automatically start atmospheric simulation. This field is not a launch command.
blocked_reasons string[] Blocking reason codes listed below. An empty array means no reasons; multiple distinct codes may be present.

handoff.json

Entry-state handoff description for external consumers.

Contains references, readiness and photometry, duplicating parts of request and manifest. It is not a complete StrewnCLI job. Current UI/Strewn preparation reads request, manifest and entries directly; handoff provides an explicit transfer description for external integration.

Handoff fields

Field Type and Allowed Values Description
schema_version integer: 1 Handoff schema version.
kind string: atmospheric_input Type of dataset being handed off.
ready boolean Matches manifest.atmospheric_input_ready, including photometric validation.
automatic_launch boolean: false The handoff does not imply automatic execution.
input.kind string: state_samples Input is a collection of states.
input.path string: entries.json Path to entry states relative to the handoff directory.
physical.absolute_magnitude number | null H from request.physical.
physical.albedo number | null Albedo from request.physical, not the atmospheric MC distribution.
source_request string: request.json Path to the original orbital calculation provenance.
blocked_reasons string[] The same blocking reasons as in manifest.

atmosphere.json

Editable job configuration for the next atmospheric Monte Carlo run.

Created during atmospheric preparation and may change between runs. It does not replace launch.json and job.json of a completed atmospheric run. Relative paths resolve from this file's directory. Unknown configuration keys are rejected. The general loader supports more options than the UI panel.

Root and input

Field Type and Allowed Values Description
schema_version integer: 1 | 2 Atmospheric job version. New jobs use 2. The retain_mass_remainder default is false in version 1 and true in version 2; an explicit physics value overrides it.
input.kind state_samples | fixed_state Orbital MC uses state_samples with path. fixed_state uses state. orbit_solution is handled by the separate StrewnOrbit adapter.
input.path string; path Required for state_samples. Absolute or relative path to a state file. Must not coexist with state.
environment_directory string; path; optional Shared source and cache directory. Defaults to output_directory/inputs when omitted. The path does not embed environment data.
output_directory string; path New result directory; must not exist or must be empty. Required for direct fixed_state/state_samples execution. The UI allocates a new folder for each run.

environment: environment preparation

Field Type and Allowed Values Description
environment.mode automatic | file | remote | idealized automatic obtains NOAA GFS, Copernicus DEM and EGM2008; file reads a snapshot; remote downloads prepared JSON; idealized uses a standard atmosphere without wind. Mode-specific fields are listed later.
environment.margin_km number; 1 ... 500 km Automatic coverage margin around entries and straight-line ground intersections. Default 25. Explicit bounds_deg specifies the region directly.
environment.terrain_step_deg number; 0.001 ... 0.1 degree Output terrain grid spacing, default 0.02 degrees. Not the DEM native resolution.
environment.timeout_seconds integer; 1 ... 3600 s Network request timeout. Defaults: automatic 120, remote 60. Not flight duration or realization timeout.
environment.max_download_bytes integer; 1 ... 1073741824 byte Limit on an individual downloaded chunk or resource. Defaults: automatic 256 MiB, remote 64 MiB. Not a total archive size limit.
environment.offline boolean; automatic True prohibits downloading missing sources: use cached or explicitly supplied local data. Default false.
environment.on_unavailable error | idealized; automatic Default error stops preparation when real environment data are unavailable. idealized permits an explicitly labelled replacement with standard atmosphere and constant terrain.

physics: physical model and fragment representation

Field Type and Allowed Values Description
physics.phase entry | dark_flight Default entry enables ablation and breakup at speeds at or above luminous_speed_mps. dark_flight starts without either mechanism.
physics.ram_pressure rho_v2 | half_rho_v2 Pressure compared with strength: rho*Vr^2 or 0.5*rho*Vr^2, where Vr is air-relative. Default rho_v2. Strength values must use the same convention.
physics.fragment_shape sphere | brick_area_only | cone_area_only Default sphere. Nonspherical variants change cross-sectional area, without modelling attitude or full nonspherical aerodynamics.
physics.min_mass_kg number > 0; kg Minimum mass of an individually resolved fragment, default 0.001. Smaller mass remains in the mass accounting but is not followed as ordinary trajectories.
physics.luminous_speed_mps number > 0; m/s Air-relative speed threshold for ablation and breakup, default 3000. A model switch, not an observed luminous endpoint.
physics.weibull_alpha number >= 0 Strength scaling exponent: S_child=min(S_cap,S_parent*(M_parent/m_child)^alpha). Default 0.2.
physics.strength_cap_pa number > 0; Pa Child-fragment strength cap, default 330000000 Pa. Not the initial body strength.
physics.lateral_coefficient number >= 0 Coefficient under the square root in the lateral separation-speed scale, default 1. Zero disables this kick; multiplying it by four doubles the speed scale.
physics.dust_at_every_breakup boolean Default true applies the dust fraction at every breakup. False applies it only to the original generation-0 body.
physics.individual_fragments integer[2] >= 0 Largest individually tracked fragments before tail grouping: [first breakup, later breakups]. Default [30,10]. Does not prescribe total fragment count.
physics.bins_per_decade integer[2]; each 1 ... 1000 Tail mass bins per log10(m) decade: [first breakup, later breakups]. Default [4,2].
physics.representatives_per_bin integer; 1 ... 1024 Representative directions per mass bin, capped by its fragment count. Multiplicities may be fractional. Defaults: API 1, new UI configuration 3.
physics.max_particles integer >= 0 Tracked trajectory limit. Zero disables it; the UI uses zero. Positive limits are supported by the CLI; a limit-reached realization is incomplete.
physics.retain_mass_remainder boolean Retain the final remainder fragment when the next mass exhausts the budget and the remainder is at least min_mass. The unresolved small-fragment tail is not combined into a large fragment. The default depends on schema_version.

integration: numerical controls

Field Type and Allowed Values Description
integration.relative_tolerance number > 0 Relative local-error tolerance, default 1e-8. Used together with absolute tolerances.
integration.position_tolerance_m number > 0; m Absolute position-component tolerance, default 0.01. Not a guarantee of final impact-location accuracy.
integration.velocity_tolerance_mps number > 0; m/s Absolute velocity-component tolerance, default 0.0001.
integration.mass_tolerance_kg number > 0; kg Absolute mass tolerance, default 1e-9. Not the minimum fragment mass threshold.
integration.initial_step_s number > 0; s Initial segment step, default 0.02. Must lie between min_step_s and max_step_s.
integration.min_step_s number > 0; s Minimum step, default 1e-10. Requiring a smaller step causes integration failure.
integration.max_step_s number >= initial_step_s; s Maximum step, default 5.
integration.max_flight_time_s number > 0; s Simulated-time limit for one segment measured from fragment birth, default 3000. Not the total cascade age or wall-clock runtime.
integration.max_step_attempts integer > 0 Maximum step attempts per segment, including rejected steps; default 1000000.

monte_carlo: atmospheric sampling

Field Type and Allowed Values Description
monte_carlo.seed uint64 Seed for entry selection, physical parameters and separation kicks. A separate generator from the orbital RNG. API default: 20230213; the UI initially uses the orbital MC seed.
monte_carlo.runs integer > 0 Maximum realizations. Defaults: API 200, new UI configuration 1000. Convergence may stop execution earlier; this count need not match entries.
monte_carlo.workers integer; 1 ... 1024 Parallel workers, default 15. In normal execution, fixed-seed results do not depend on worker count. Not the orbital OpenMP setting.
monte_carlo.run_timeout_s number; 0 < value <= 86400 s Wall-clock limit for one realization and its cascade, excluding queue wait. Default 300. Zero does not disable it; exceeding the limit makes the realization incomplete.
monte_carlo.convergence object | null; optional Early-stopping configuration. Null or omission disables it. The UI uses an object.

monte_carlo.convergence: convergence grid

Field Type and Allowed Values Description
monte_carlo.convergence.threshold number; 0 < value <= 1 Jensen–Shannon divergence threshold using log2, not its square root; default 0.02. Both count and mass maps must pass. It does not mean 2% result error.
monte_carlo.convergence.batch_size integer > 0 Check interval in completed realizations, default 50. The first accumulated map establishes the comparison baseline.
monte_carlo.convergence.consecutive_checks integer > 0 Required consecutive successful checks, default 3. A failed check resets the counter.
monte_carlo.convergence.center_deg number[2]; degree Required centre [latitude,longitude]: |lat|<89, |lon|<=180. Independent of the report map centre.
monte_carlo.convergence.half_size_km number[2] > 0; km Half-extents [north–south,east–west], default [14,20]. At least two cells per axis, at most 4 million total. Impacts outside the grid prevent convergence certification.
monte_carlo.convergence.cell_m number > 0; m Convergence-grid cell size, API default 25; the UI adjusts it for coverage. Distinct from maps.cell_m.
monte_carlo.convergence.kernel_sigma_m number > 0; m Fixed convergence-KDE sigma, default 60; its ratio to cell_m must not exceed 64. Independent of the adaptive report map.

monte_carlo.parameters: distributions

Field Type and Allowed Values Description
monte_carlo.parameters.size.absolute_magnitude number H for photometric size. D=1329e3*10^(-H/5)/sqrt(albedo) metres; mass is pi*rho*D^3/6. The UI reads H from request. Mutually exclusive with mass_kg or diameter_m.
monte_carlo.parameters.size.albedo number[3]: [min,mode,max] Triangular distribution: 0<min<=mode<=max<=1. Equal values fix albedo. Required with H; not a uniform range.
monte_carlo.parameters.density_kg_m3 number | number[2]; kg/m^3 Positive density: a scalar fixes the value; [min,max] specifies a uniform draw. Affects mass and ballistics.
monte_carlo.parameters.strong_strength_pa number | number[2]; Pa Positive initial strength of the strong branch, selected with probability 1-weak_probability. Ranges are uniform.
monte_carlo.parameters.weak_strength_pa number | number[2]; Pa Positive initial strength of the weak branch, selected with probability weak_probability. Not sampled at zero probability, but still validated.
monte_carlo.parameters.weak_probability number; 0 ... 1 Weak-branch probability: zero selects only strong, one only weak, otherwise a mixture. The UI uses zero.
monte_carlo.parameters.ablation_kg_j number | number[2]; kg/J; >= 0 Coefficient sigma in dm/dt=-0.5*sigma*rho_air*A*Vr^3 when ablation is enabled. Uniform range or fixed value; zero disables this mass-loss mechanism.
monte_carlo.parameters.dust_fraction number | number[2]; 0 ... 1 Parent mass fraction assigned to dust at applicable breakups. Uniform range; one leaves zero mass for discrete children.
monte_carlo.parameters.largest_fraction number | number[2]; 0 < value < 1 Largest fragment fraction of mass after dust removal. Uniform range or scalar.
monte_carlo.parameters.beta number | number[2]; 0 < value < 1 Exponent of the cumulative power-law mass generator. Controls the mass distribution and fragment count; ranges are uniform.
monte_carlo.parameters.wind_scale number | number[2]; >= 0 Wind-vector multiplier. Zero disables wind, one preserves it; ranges are uniform.
monte_carlo.parameters.drag_scale number | number[2]; >= 0 Multiplier of Cd(M). One preserves the baseline model, zero disables this drag; ranges are uniform.

maps object | null; optional An object enables the report and GIS export; omission or null disables them. Numerical results are preserved independently of rendering success.

maps.adaptive_alpha number; 0 ... 1 Local kernel-width adaptation exponent, default 0.5. Not applied in fixed mode.

maps.center_deg number[2] | null; degree Fixed centre [latitude,longitude], |lat|<85, |lon|<=180. Null or omission enables automatic field coverage.
maps.half_size_km number[2]; 0 < each <= 1000 km Half-extents [north–south,east–west], default [14,20]. With an automatic centre, effective coverage is derived from impacts rather than this pair.
maps.basemap none | esri_imagery Basemap: API default none, new UI configuration esri_imagery. Does not affect the integration environment.

Compatibility and Import

The following are legacy fields and alternative forms accepted by general atmospheric import. UI orbital handoff preparation requires a stricter 100 km entry format.

Field Type and Allowed Values Description
entries[].weight number >= 0; optional New orbital exports omit this field; absence means 1. Legacy weight:1 is accepted. General atmospheric import supports nonunit weights with a positive sum; the UI handoff requires unit weights. Not fragment multiplicity.
manifest.probability_scope string; legacy Legacy explanatory probability-scope string. No longer written or used by the loader.
entries.frame_model string; legacy Older archives may contain IAU1976/1980 UT1/GAST, no polar motion without an EOP profile. The profile cannot be reliably recovered from this string alone.
epoch_jd_utc number; JD UTC General import accepts this instead of epoch_mjd_utc, never alongside it. Converted by subtracting 2400000.5.
latitude_deg number; degree Alternative geodetic input, together with longitude_deg, height_wgs84_m and velocity_enu_mps instead of the ECEF vector pair.
longitude_deg number; degree Longitude of alternative geodetic input, east-positive.
height_wgs84_m number; m Alternative entry height above WGS84. Not height above local ground or DEM orthometric height.
velocity_enu_mps number[3]; m/s Alternative entry velocity [east,north,up], converted to ECEF. Geodetic and ECEF fields must not be mixed.
r_itrs / v_itrs / jd_utc number[3] / number[3] / number Legacy entry file without schema_version: position in metres, velocity in m/s, epoch in JD UTC. Accepted by the general loader, not by UI orbital handoff preparation.
maps.image_width integer; 800 ... 4096; legacy Legacy raster width, default 1600. Accepted but unused by the current HTML renderer and omitted on re-export.
maps.font_file string; path; legacy Legacy raster font path. Accepted but unused by the current HTML renderer and omitted on re-export.
