Состав архива

Архив MC сохраняет постановку и результаты орбитального Monte Carlo, а также входные состояния для последующего атмосферного расчёта. Один каталог run соответствует одному орбитальному запуску. Атмосферные реализации, распады и падения сохраняются в отдельной папке результатов. 

MC/
  run-<id>/
    request.json
    result.json
    entries.json
    manifest.json
    handoff.json
    atmosphere.json

request, result, entries, handoff и manifest создаются орбитальным экспортёром. atmosphere добавляется при подготовке атмосферного задания; сразу после чисто орбитального экспорта этого файла может ещё не быть.

Файл Назначение
request.json Исходные данные и настройки орбитального Monte Carlo.
result.json Численный результат орбитального MC: счётчики и пересечения границы.
entries.json Готовые состояния входа для атмосферного расчёта, в единицах СИ.
manifest.json Статус орбитального расчёта и готовность входов к следующему этапу.
handoff.json Описание передачи входных состояний внешнему потребителю.
atmosphere.json Редактируемое задание следующего атмосферного Monte Carlo.

request.json

Исходные данные и настройки орбитального Monte Carlo.

Содержит номинальное состояние, полную ковариацию, параметры выборки и распространения.

Общие сведения

Поле Тип и допустимые значения Описание
schema_version integer: 1 Версия схемы запроса, не версия приложения.
object string Обозначение объекта. Используется для идентификации и заголовка отчёта.
sampling_kind state_covariance | parameter_covariance Источник выборки: шесть компонент состояния либо состояние совместно с оцениваемыми негравитационными параметрами. Во втором режиме при отсутствии таких параметров размерность также равна 6.
external_ephemerides_embedded boolean: false Внешние эфемериды в эти JSON не вложены. Для повторного орбитального распространения требуются отдельно.

nominal: номинальное состояние

Поле Тип и допустимые значения Описание
nominal.frame string: heliocentric ECLM J2000 Гелиоцентрическая эклиптическая система J2000. Определяет начало и ориентацию осей векторов.
nominal.epoch_mjd_tdb number; MJD TDB Эпоха состояния. JD = MJD + 2400000.5; шкалу TDB нельзя подменять UTC.
nominal.position_au number[3]; AU Положение [x,y,z] на указанную эпоху.
nominal.velocity_au_day number[3]; AU/day Скорость [vx,vy,vz]. В экспортируемом значении преобразование из внутренних единиц уже выполнено.

covariance: неопределённость

Поле Тип и допустимые значения Описание
covariance.matrix number[n][n]; n = 6 ... 10 Полная ковариационная матрица, включая корреляции. Диагональ содержит дисперсии, а не сигмы. Единицы Cij равны произведению единиц параметров i и j.
covariance.parameter_order string[n] Порядок строк и столбцов: x_au, y_au, z_au, vx_au_day, vy_au_day, vz_au_day; затем выбранные a1_au_day2, a2_au_day2, a3_au_day2, dt_day.
covariance.objective_scale_already_applied number > 0 Множитель ковариации, уже применённый перед MC. Для сигм соответствующий множитель равен квадратному корню. Повторно применять к matrix нельзя.
covariance.additional_scale number: 1 Паспортное поле: текущий экспорт записывает 1. Не является отдельным переключателем генератора.
covariance.valid boolean Проверка размерности, конечности, положительных диагоналей, симметрии и спектра. Допуск асимметрии: 1e-10 нормы матрицы; минимум собственных значений корреляционной матрицы: -1e-10.

non_grav: негравитационная модель

Поле Тип и допустимые значения Описание
non_grav.enabled boolean Включено ли негравитационное ускорение.
non_grav.model integer: 0 ... 4 0: None; 1: MarsdenH2O; 2: MarsdenCO; 3: InverseSquare; 4: Yarkovsky (A2).
non_grav.fit_mask integer; bit mask Оцениваемые параметры: A1=1, A2=2, A3=4, DT=8; комбинации складываются. 0 означает отсутствие оцениваемых NG-параметров. Допустимая маска зависит от модели; фиксированные коэффициенты не обязаны входить в маску.
non_grav.a1_au_day2 number; AU/day^2 Номинальный радиальный коэффициент A1.
non_grav.a2_au_day2 number; AU/day^2 Номинальный поперечный коэффициент A2.
non_grav.a3_au_day2 number; AU/day^2 Номинальный коэффициент A3 по нормали к плоскости орбиты.
non_grav.dt_day number; day Сдвиг времени в законе активности для моделей, которые его поддерживают. Не поправка к эпохам наблюдений.

monte_carlo: орбитальная выборка

Поле Тип и допустимые значения Описание
monte_carlo.clones integer > 0 Запрошенное число орбитальных клонов. Не число атмосферных реализаций или осколков.
monte_carlo.seed uint64 Seed генерации клонов. Хранить как целое без потери точности; для воспроизведения также нужен тот же алгоритм RNG.
monte_carlo.rng string Идентификатор алгоритма: SplitMix64 keyed Box-Muller; clone ID and parameter index. Описывает детерминированную привязку случайных чисел к клону и параметру.
monte_carlo.altitude_km number >= 0; km Граница остановки орбитального распространения. Положительное значение задаёт геодезическую высоту; 0 сохраняет старую сферическую границу. Для передачи в атмосферный MC через UI требуется 100 км.
monte_carlo.noise_sigma_mult number Множитель сигм выборки в общем API: положительное значение применяется к фактору ковариации, неположительное заменяется на 1. UI задаёт 1. Не путать с уже применённым масштабом matrix.
monte_carlo.noise_sigma_mult_applies boolean: false Текущий экспорт жёстко записывает false; это не управление генератором.
monte_carlo.openmp_max_threads integer >= 1 Максимум потоков OpenMP на момент экспорта, а не измеренное число одновременно работавших потоков. Без OpenMP записывается 1.

propagation: динамика и события

Поле Тип и допустимые значения Описание
propagation.integrator RA15 | IAS15 Выбранный орбитальный интегратор.
propagation.accuracy number > 0 Параметр точности выбранного интегратора. Значение не является погрешностью положения в метрах; критерии RA15 и IAS15 различаются.
propagation.step_days number; day Начальный шаг орбитального интегратора. Внутренние шаги адаптивны; поле не задаёт интервал записи или верхний предел шага.
propagation.planet_mask integer; bit mask Биты 0–7: Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, Neptune; 8–10: Ceres, Pallas, Vesta в резервной кеплеровской модели; 11: Moon. Солнце этой маской не отключается. При доступном SB441 его астероиды включаются отдельно.
propagation.sb441 boolean При true и доступном SPK-источнике используются 16 астероидов SB441-N16 независимо от битов 8–10. Иначе действует резервная тройка по маске. Файлы эфемерид здесь не вложены.
propagation.encounter_points integer Настройка сгущения шагов около сближения. Не число клонов или точек падения.
propagation.earth_encounter_radius_au number > 0; AU Радиус окрестности Земли для управления шагом около сближения. Не радиус Земли и не высота входа.
propagation.inactive_interior_mass_policy integer: 0 | 1 0: ExplicitOnly, только явно включённые возмущения. 1: SmoothCentralMass, плавный учёт масс отключённых внутренних планет в центральной массе.
propagation.event_window_days number: 1; day Полуширина окна привязки пересечения к номинальному событию: плюс-минус одни сутки.
propagation.events object[] Номинальные сближения. Порядок массива задаёт индексы event в result.json и порядок hits_per_event.
propagation.events[].planet integer: 0 ... 8 Идентификатор тела, не битовая маска: 0 Mercury, 1 Venus, 2 Earth, 3 Mars, 4 Jupiter, 5 Saturn, 6 Uranus, 7 Neptune, 8 Moon.
propagation.events[].epoch_mjd_tdb number; MJD TDB Эпоха номинального сближения, не время входа отдельного клона.
propagation.events[].distance_au number >= 0; AU Расстояние от объекта до центра целевого тела в номинальном событии, не высота над поверхностью.
propagation.events[].position_au number[3]; AU Гелиоцентрическое положение объекта в событии, в осях орбитального распространения J2000.
propagation.events[].velocity_au_day number[3]; AU/day Гелиоцентрическая скорость объекта в тех же осях.
propagation.events[].planet_position_au number[3]; AU Гелиоцентрическое положение целевого тела в ту же эпоху. Разность положений даёт относительный вектор.
propagation.events[].planet_velocity_au_day number[3]; AU/day Гелиоцентрическая скорость целевого тела. Разность скоростей даёт относительную инерциальную скорость.

physical: фотометрия

Поле Тип и допустимые значения Описание
physical.absolute_magnitude number | null Абсолютная звёздная величина H. null означает отсутствие оценки; не путать с видимой яркостью. Используется для размера тела по H и альбедо.
physical.albedo number | null; 0 < p <= 1 Альбедо орбитального архива. Для общей готовности handoff требуется допустимое число. Атмосферный MC использует собственное распределение альбедо из atmosphere.json.

result.json

Численный результат орбитального MC: счётчики и пересечения границы.

crossings содержит только подтверждённые пересечения, а не все начальные клоны или их пошаговые траектории. Успешное распространение клона не обязательно заканчивается пересечением. Вероятность относится к выбранной границе, а не к выживанию метеоритов на земле.

Сводка

Поле Тип и допустимые значения Описание
schema_version integer: 1 Версия схемы результата.
altitude_km number >= 0; km Граница, к которой относятся записи. Соответствует request.monte_carlo.altitude_km.
attempted integer >= 0 В covariance MC инициализируется запрошенным числом клонов. При отмене не является точным счётчиком реально начатых попыток.
completed integer >= 0 Успешно распространённые клоны, включая клоны без пересечений. Знаменатель эмпирической вероятности.
failed integer >= 0 Клоны с ошибкой распространения или обработки. Не трактовать их как физические промахи.
cancelled boolean Был ли расчёт отменён. При true файл может содержать частичные результаты.
any_crossing_clones integer >= 0 Число уникальных клонов с хотя бы одним пересечением среди выбранных событий.
hits_per_event integer[] Число пересечений по каждому событию в порядке request.propagation.events. Сумма может превышать any_crossing_clones.
empirical_crossing_probability number; 0 ... 1 any_crossing_clones/completed при completed>0; иначе 0. Значение 1 не гарантирует падения выживших фрагментов на землю.
crossings object[] Пересечения границы. Возможны пустой массив, частичный результат и несколько событий одного клона.

crossings[]: запись пересечения

Поле Тип и допустимые значения Описание
crossings[].clone integer; 0 ... clones-1 Индекс клона в генераторе. Не заменять индексом строки массива.
crossings[].event integer; 0 ... events.length-1 Индекс события request.propagation.events.
crossings[].planet integer: 0 ... 8 Целевое тело; тот же enum, что в request.propagation.events[].planet.
crossings[].epoch_mjd_tdb number; MJD TDB Уточнённая эпоха пересечения в орбитальной шкале времени.
crossings[].epoch_mjd_utc number; MJD UTC Тот же физический момент в UTC; используется атмосферным этапом и выбором погоды.
crossings[].body_fixed_valid boolean Получены ли координаты во вращающейся системе тела. false блокирует готовность атмосферного входа.
crossings[].position_body_fixed_km number[3]; km Положение [x,y,z] от центра тела во вращающихся осях. Для Земли используется экспортируемая модель ECEF.
crossings[].velocity_body_fixed_km_s number[3]; km/s Производная координат во вращающихся осях, с учётом вращения системы. Для entries умножается на 1000.
crossings[].latitude_deg number; degree Широта, производная от положения. Для Земли геодезическая WGS84; для других тел используется их эллипсоид или сфера.
crossings[].longitude_deg number; degree Долгота во вращающейся системе, восток положительный, около диапазона [-180,180].
crossings[].relative_speed_km_s number >= 0; km/s Модуль инерциальной скорости относительно целевого тела. Не скорость относительно ветра и не обязательно норма body-fixed скорости.
crossings[].diagnostic_miss_km number | null; km Локальная двухтельная оценка расстояния перицентра от центра тела. Не промах относительно поверхности и не критерий пересечения. null означает нечисловую оценку.

entries.json

Готовые состояния входа для атмосферного расчёта, в единицах СИ.

Файл передаётся как input.kind=state_samples. UI принимает полный набор уникальных входящих земных состояний на 100 км для одного события. Все экспортируемые орбитальные входы имеют одинаковый вес; поле weight не записывается. Дублирование части result.json намеренное: атмосферный модуль читает самостоятельный формат входа.

Описание набора

Поле Тип и допустимые значения Описание
schema_version integer: 1 Версия схемы входных состояний.
frame string: ECEF Положение и скорость заданы в геоцентрических вращающихся осях, не в инерциальных.
frame_model string Описание преобразования, записанное при расчёте MC. Называет применённую цепочку, полярное движение и профиль EOP отдельно. Текущий путь использует IAU1976/1980, UT1/GAST IAU1982, finals2000A с резервом UTC и не применяет полярное движение. При отсутствии происхождения во внешнем результате: unknown (not recorded).
altitude_km number >= 0; km Высота границы орбитального этапа. Для UI требуется 100; высота каждого вектора дополнительно проверяется с допуском 1 м.
boundary WGS84 geodetic height | legacy sphere Определение поверхности остановки: геодезическая высота при altitude_km>0, старая сфера при 0.
entries object[] Входные состояния. Полнота проверяется относительно запрошенного числа орбитальных клонов.

entries[]: одно состояние

Поле Тип и допустимые значения Описание
entries[].id uint64 Уникальный ключ входа: cloneIndex × число событий + eventIndex. При одном событии совпадает с индексом клона. Связан с entry_id атмосферной реализации.
entries[].epoch_mjd_utc number; MJD UTC Момент входа. Хранить с точностью float64; перевод в округлённый JD может потерять точность.
entries[].position_ecef_m number[3]; m Положение [x,y,z]. Соответствует position_body_fixed_km из result, умноженному на 1000.
entries[].velocity_ecef_mps number[3]; m/s Скорость [vx,vy,vz] во вращающихся осях; ветер ещё не вычтен.

manifest.json

Статус орбитального расчёта и готовность входов к следующему этапу.

Записывается последним среди пяти файлов орбитального экспорта. Статус complete сам по себе не означает корректную атмосферную передачу: необходимо учитывать флаги готовности. Подготовка в UI проверяет schema_version, status и entry_states_ready.

Поля статуса

Поле Тип и допустимые значения Описание
schema_version integer: 1 Версия схемы manifest.
status complete | partial | cancelled cancelled при отмене; иначе partial при ошибках или неполном числе завершённых клонов; иначе complete. Этот экспорт не записывает running или failed.
entry_states_ready boolean Все проверки ковариации, полноты, идентификаторов, геометрии и входящих состояний пройдены. Наличие H/альбедо в этот флаг не входит.
atmospheric_input_ready boolean Общая готовность: корректные entries плюс конечный H и альбедо 0<p≤1. UI проверяет H отдельно и использует собственное распределение альбедо.
automatic_launch boolean: false Запись архива сама по себе не запускает атмосферный расчёт. Поле не является командой запуска.
blocked_reasons string[] Коды причин блокировки из таблицы ниже. Пустой массив означает отсутствие причин; возможно несколько кодов без повторов.

handoff.json

Описание передачи входных состояний внешнему потребителю.

Содержит ссылки, готовность и фотометрию, дублирующие части request и manifest. Не является полным заданием StrewnCLI. В текущем пути UI/Strewn подготовка читает request, manifest и entries напрямую; handoff предназначен для явного описания передачи и внешней интеграции.

Поля передачи

Поле Тип и допустимые значения Описание
schema_version integer: 1 Версия схемы передачи.
kind string: atmospheric_input Тип передаваемого набора.
ready boolean Повторяет manifest.atmospheric_input_ready, включая проверку фотометрии.
automatic_launch boolean: false Передача не подразумевает автоматического запуска.
input.kind string: state_samples Вход представлен набором состояний.
input.path string: entries.json Путь к входам относительно каталога handoff.
physical.absolute_magnitude number | null H из request.physical.
physical.albedo number | null Альбедо из request.physical, а не распределение атмосферного MC.
source_request string: request.json Путь к паспорту исходного орбитального расчёта.
blocked_reasons string[] Те же причины блокировки, что в manifest.

atmosphere.json

Редактируемое задание следующего атмосферного Monte Carlo.

Создаётся при подготовке атмосферного этапа и может изменяться между запусками. Не заменяет launch.json и job.json уже выполненного атмосферного расчёта. Относительные пути разрешаются от каталога этого файла. Неизвестные конфигурационные ключи отклоняются. Общий загрузчик поддерживает больше вариантов, чем панель UI.

Корень и вход

Поле Тип и допустимые значения Описание
schema_version integer: 1 | 2 Версия атмосферного задания. Новые задания: 2. В версии 1 retain_mass_remainder по умолчанию false, в 2 true; явное поле physics переопределяет это значение.
input.kind state_samples | fixed_state Для орбитального MC используется state_samples с path. fixed_state использует state. orbit_solution обслуживается отдельным адаптером StrewnOrbit.
input.path string; path Обязателен для state_samples. Абсолютный путь или относительный путь к файлу состояний. Не допускается вместе с state.
environment_directory string; path; optional Общий каталог источников и кэша. При отсутствии используется output_directory/inputs. Путь не содержит самих данных среды.
output_directory string; path Каталог нового результата; должен отсутствовать или быть пустым. Обязателен для прямого fixed_state/state_samples запуска. UI выделяет новую папку при каждом запуске.

environment: подготовка среды

Поле Тип и допустимые значения Описание
environment.mode automatic | file | remote | idealized automatic получает NOAA GFS, Copernicus DEM и EGM2008; file читает готовый снимок; remote загружает подготовленные JSON; idealized использует стандартную атмосферу без ветра. Дополнительные поля режимов приведены далее.
environment.margin_km number; 1 ... 500 km Запас автоматического охвата вокруг входов и прямолинейных пересечений земли. По умолчанию 25. Явный bounds_deg задаёт область напрямую.
environment.terrain_step_deg number; 0.001 ... 0.1 degree Шаг выходной сетки рельефа, по умолчанию 0.02°. Не нативное разрешение DEM.
environment.timeout_seconds integer; 1 ... 3600 s Сетевой таймаут запроса. По умолчанию automatic: 120, remote: 60. Не время полёта и не таймаут реализации.
environment.max_download_bytes integer; 1 ... 1073741824 byte Лимит отдельной загружаемой порции или ресурса. По умолчанию automatic: 256 MiB, remote: 64 MiB. Не ограничивает общий размер архива.
environment.offline boolean; automatic true запрещает скачивание отсутствующих источников: используется кэш или явно заданный локальный источник. По умолчанию false.
environment.on_unavailable error | idealized; automatic По умолчанию error: отсутствие реальной среды останавливает подготовку. idealized разрешает явно помеченную замену стандартной атмосферой и постоянной поверхностью.

physics: физика и представление фрагментов

Поле Тип и допустимые значения Описание
physics.phase entry | dark_flight По умолчанию entry: абляция и распады разрешены при скорости не ниже luminous_speed_mps. dark_flight начинает расчёт без них.
physics.ram_pressure rho_v2 | half_rho_v2 Давление для сравнения с прочностью: ρVr² или ½ρVr², где Vr относительно воздуха. По умолчанию rho_v2. Значения прочности должны соответствовать этому соглашению.
physics.fragment_shape sphere | brick_area_only | cone_area_only По умолчанию sphere. Несферические варианты меняют площадь сечения, но не моделируют ориентацию или полную несферическую аэродинамику.
physics.min_mass_kg number > 0; kg Минимальная масса отдельного учитываемого фрагмента, по умолчанию 0.001. Более мелкая масса учитывается в балансе, но не ведётся обычными траекториями.
physics.luminous_speed_mps number > 0; m/s Порог относительной скорости для абляции и распадов, по умолчанию 3000. Модельный переключатель, не наблюдаемая граница свечения.
physics.weibull_alpha number >= 0 Показатель усиления прочности при уменьшении массы: S_child=min(S_cap,S_parent*(M_parent/m_child)^alpha). По умолчанию 0.2.
physics.strength_cap_pa number > 0; Pa Предел прочности дочерних фрагментов, по умолчанию 330000000 Па. Не начальная прочность тела.
physics.lateral_coefficient number >= 0 Коэффициент под корнем в масштабе поперечной скорости разлёта, по умолчанию 1. Ноль отключает этот импульс; увеличение в четыре раза удваивает масштаб скорости.
physics.dust_at_every_breakup boolean По умолчанию true: доля пыли применяется при каждом распаде. false: только при распаде исходного тела поколения 0.
physics.individual_fragments integer[2] >= 0 Число крупнейших индивидуальных фрагментов до группировки хвоста: [первый распад, последующие]. По умолчанию [30,10]. Не задаёт полное число осколков.
physics.bins_per_decade integer[2]; each 1 ... 1000 Число массовых интервалов на декаду log10(m) для хвоста: [первый распад, последующие]. По умолчанию [4,2].
physics.representatives_per_bin integer; 1 ... 1024 Число направлений-представителей в массовом интервале, не более числа его осколков. Кратности могут быть дробными. По умолчанию API: 1, новый UI-конфиг: 3.
physics.max_particles integer >= 0 Лимит числа учитываемых траекторий. 0 отключает лимит; UI устанавливает 0. Положительное значение поддерживается CLI; достигшая лимита реализация неполна.
physics.retain_mass_remainder boolean Сохранять последний остаточный фрагмент, если следующая масса исчерпывает бюджет и остаток не меньше min_mass. Мелкий недоразрешённый хвост не объединяется в большой осколок. Значение по умолчанию зависит от schema_version.

integration: численные допуски

Поле Тип и допустимые значения Описание
integration.relative_tolerance number > 0 Относительная часть допуска локальной ошибки, по умолчанию 1e-8. Совместно используется с абсолютными допусками.
integration.position_tolerance_m number > 0; m Абсолютный допуск компоненты положения, по умолчанию 0.01. Не гарантия точности конечного места падения.
integration.velocity_tolerance_mps number > 0; m/s Абсолютный допуск компоненты скорости, по умолчанию 0.0001.
integration.mass_tolerance_kg number > 0; kg Абсолютный допуск по массе, по умолчанию 1e-9. Не порог минимальной массы.
integration.initial_step_s number > 0; s Стартовый шаг участка, по умолчанию 0.02. Должен лежать между min_step_s и max_step_s.
integration.min_step_s number > 0; s Минимальный шаг, по умолчанию 1e-10. Если требуемый шаг меньше, интегрирование завершается ошибкой.
integration.max_step_s number >= initial_step_s; s Верхний предел шага, по умолчанию 5.
integration.max_flight_time_s number > 0; s Лимит моделируемого времени одного сегмента от рождения фрагмента, по умолчанию 3000. Не общий возраст каскада и не реальное время выполнения.
integration.max_step_attempts integer > 0 Максимум попыток шага одного сегмента, включая отклонённые; по умолчанию 1000000.

monte_carlo: атмосферная выборка

Поле Тип и допустимые значения Описание
monte_carlo.seed uint64 Seed выбора входов, физических параметров и разлёта. Это отдельный генератор, не орбитальный RNG. По умолчанию API: 20230213; UI первоначально берёт seed орбитального MC.
monte_carlo.runs integer > 0 Максимум реализаций. По умолчанию API: 200, новый UI-конфиг: 1000. Сходимость может остановить расчёт раньше; число не обязано совпадать с entries.
monte_carlo.workers integer; 1 ... 1024 Параллельные исполнители, по умолчанию 15. При штатном расчёте фиксированный seed не зависит от их числа. Не настройка orbital OpenMP.
monte_carlo.run_timeout_s number; 0 < value <= 86400 s Реальное время одной реализации вместе с каскадом, без ожидания очереди. По умолчанию 300. Ноль не отключает таймаут; превышение делает реализацию неполной.
monte_carlo.convergence object | null; optional Настройки досрочной остановки. null или отсутствие отключает критерий. UI использует объект.

monte_carlo.convergence: контрольная сетка

Поле Тип и допустимые значения Описание
monte_carlo.convergence.threshold number; 0 < value <= 1 Порог дивергенции Jensen–Shannon с log2, без квадратного корня; по умолчанию 0.02. Обе карты количества и массы должны пройти проверку. Не означает ошибку результата 2%.
monte_carlo.convergence.batch_size integer > 0 Интервал проверки по завершённым реализациям, по умолчанию 50. Первая накопленная карта задаёт базу сравнения.
monte_carlo.convergence.consecutive_checks integer > 0 Необходимое число успешных проверок подряд, по умолчанию 3. Неудачная проверка сбрасывает счётчик.
monte_carlo.convergence.center_deg number[2]; degree Обязательный центр [широта,долгота]: |lat|<89, |lon|≤180. Независим от центра карты отчёта.
monte_carlo.convergence.half_size_km number[2] > 0; km Полуразмеры [север–юг,запад–восток], по умолчанию [14,20]. Не менее двух ячеек на ось, не более 4 млн суммарно. Падения за пределами сетки блокируют вывод о сходимости.
monte_carlo.convergence.cell_m number > 0; m Ячейка контрольной сетки, по умолчанию API: 25; UI подбирает с учётом охвата. Не maps.cell_m.
monte_carlo.convergence.kernel_sigma_m number > 0; m Сигма фиксированного контрольного KDE, по умолчанию 60; отношение к cell_m не более 64. Независима от адаптивной карты отчёта.

monte_carlo.parameters: распределения

Поле Тип и допустимые значения Описание
monte_carlo.parameters.size.absolute_magnitude number H в фотометрической модели размера. D=1329e3*10^(-H/5)/sqrt(albedo) м; масса πρD³/6. UI берёт H из request. Не допускается совместно с mass_kg или diameter_m.
monte_carlo.parameters.size.albedo number[3]: [min,mode,max] Треугольное распределение: 0<min≤mode≤max≤1. Равные значения фиксируют альбедо. Обязательно вместе с H; не равномерный диапазон.
monte_carlo.parameters.density_kg_m3 number | number[2]; kg/m^3 Положительная плотность: скаляр фиксирует значение, [min,max] задаёт равномерную выборку. Влияет на массу и баллистику.
monte_carlo.parameters.strong_strength_pa number | number[2]; Pa Положительная начальная прочность сильной ветви, выбираемой с вероятностью 1−weak_probability. Диапазон равномерный.
monte_carlo.parameters.weak_strength_pa number | number[2]; Pa Положительная начальная прочность слабой ветви, выбираемой с вероятностью weak_probability. При нулевой вероятности не выбирается, но валидируется.
monte_carlo.parameters.weak_probability number; 0 ... 1 Вероятность слабой ветви: 0 только strong, 1 только weak, иначе смесь. UI устанавливает 0.
monte_carlo.parameters.ablation_kg_j number | number[2]; kg/J; >= 0 Коэффициент σ в dm/dt=−½σρair*A*Vr³ при включённой абляции. Равномерный диапазон или фиксированное значение; ноль отключает потерю массы этим механизмом.
monte_carlo.parameters.dust_fraction number | number[2]; 0 ... 1 Доля массы родителя, уходящая в пыль при применимом распаде. Равномерный диапазон; 1 оставляет нулевую массу дискретных детей.
monte_carlo.parameters.largest_fraction number | number[2]; 0 < value < 1 Доля крупнейшего фрагмента от массы после удаления пыли. Равномерный диапазон или скаляр.
monte_carlo.parameters.beta number | number[2]; 0 < value < 1 Показатель cumulative power-law генератора масс. Определяет распределение и число фрагментов; диапазон равномерный.
monte_carlo.parameters.wind_scale number | number[2]; >= 0 Множитель вектора ветра. 0 отключает ветер, 1 сохраняет исходный; диапазон равномерный.
monte_carlo.parameters.drag_scale number | number[2]; >= 0 Множитель Cd(M). 1 сохраняет базовую модель, 0 выключает это сопротивление; диапазон равномерный.

maps: отчёт и GIS

Поле Тип и допустимые значения Описание
maps object | null; optional Объект включает отчёт и GIS-экспорт; отсутствие или null отключает их. Численные результаты сохраняются отдельно от успешности визуализации.
maps.title string Заголовок отчёта, по умолчанию Strewn field. UI использует обозначение объекта.
maps.method adaptive | fixed Метод KDE. По умолчанию adaptive; Scott не является выбираемым режимом.
maps.cell_m number > 0; m Запрашиваемая ячейка карты, по умолчанию 25. При auto_cell_size итоговая ячейка может быть крупнее.
maps.auto_cell_size boolean По умолчанию true: разрешено укрупнение сетки при ограничениях памяти/FFT. Не связано со скоростью анимации или физикой.
maps.fixed_sigma_m number > 0; m Сигма fixed KDE, по умолчанию 60. В adaptive также используется как резерв при вырожденной выборке и при оценке охвата/памяти.
maps.adaptive_alpha number; 0 ... 1 Показатель адаптации локальной ширины ядра, по умолчанию 0.5. В fixed не применяется.
maps.adaptive_limits number[2]; 0 < min < max <= 10 Пределы множителя локальной ширины, по умолчанию [0.2,5].
maps.adaptive_classes integer; 1 ... 32 Дискретные классы адаптивной ширины ядра, по умолчанию 16.
maps.center_deg number[2] | null; degree Фиксированный центр [широта,долгота], |lat|<85, |lon|≤180. null или отсутствие включает автоматический охват поля.
maps.half_size_km number[2]; 0 < each <= 1000 km Полуразмеры [север–юг,запад–восток], по умолчанию [14,20]. При автоматическом центре итоговый охват определяется по падениям, а не этой парой.
maps.basemap none | esri_imagery Подложка: по умолчанию API none, новый UI-конфиг esri_imagery. Не влияет на среду интегрирования.
maps.offline boolean Офлайн-политика подложки. true запрещает онлайн-тайлы; false разрешает сеть с резервом встроенных тайлов. Отдельна от environment.offline.

Причины блокировки

manifest.blocked_reasons и handoff.blocked_reasons используют один набор кодов. Пустой массив означает отсутствие причин блокировки.

Поле Описание
invalid_input_covariance Некорректна размерность, конечность, диагональ, симметрия или спектр ковариации.
fitted_non_grav_covariance_not_sampled Выбрана state_covariance при наличии оцениваемых NG-параметров.
cancelled MC отменён.
incomplete_clones attempted или completed не совпадает с запрошенным числом клонов.
failed_clones Есть ошибки клонов.
not_all_clones_crossed Не все запрошенные клоны пересекли границу.
requires_100_km_entry_boundary Граница не 100 км либо высоты запроса и результата различаются.
inconsistent_event_counts Размер или значения hits_per_event не согласованы с событиями и строками crossings.
invalid_clone_or_event_id Индекс клона или события вне допустимых пределов.
multiple_crossings_per_clone Один клон имеет несколько записей пересечения.
non_earth_crossing Целевое тело пересечения или события не Земля.
invalid_entry_state Некорректна система, векторы или эпохи входа.
entry_height_mismatch Высота, восстановленная из положения, отличается от заданной более чем на 1 м.
entry_not_inbound Геодезия некорректна либо вертикальная скорость не направлена внутрь.
inconsistent_clone_count Число уникальных клонов не равно any_crossing_clones.
requires_one_encounter Пересечения относятся не ровно к одному событию.
incomplete_entry_states Число подготовленных entries не равно запрошенному числу клонов.
missing_H_or_albedo Нет конечного H или корректного альбедо 0<p≤1. Эта причина не сбрасывает уже вычисленный entry_states_ready.

Дополнительные варианты atmosphere.json

Эти поля зависят от выбранного режима и могут отсутствовать в конфигурации UI. Режимы среды имеют разные наборы допустимых ключей; нельзя переносить ключи одного режима в другой произвольно.

Поле Тип и допустимые значения Описание
input.state object; fixed_state Один объект входа вместо input.path. Те же epoch, положение, скорость, id, что у entries[].
environment.bounds_deg number[4]; degree; automatic Границы [south,north,west,east]: упорядочены, широты в [-85,85], долготы в [-179.5,179.5], размах каждой оси ≤30°. Должны покрывать входы и оценочные пересечения земли.
environment.cycle_mjd_utc number; MJD UTC; automatic Явный цикл GFS; допустимость проверяется источником. Не вместе с gfs_file.
environment.gfs_file string; path; automatic Локальный GFS GRIB вместо сетевого выбора. Не вместе с cycle_mjd_utc.
environment.path string; path; file Обязательный путь к готовому JSON-снимку среды. Используется для повторения атмосферного расчёта без скачивания.
environment.weather_url string; HTTP(S); remote Обязательный URL подготовленного JSON атмосферы, не сырого GRIB.
environment.terrain_url string; HTTP(S); remote Обязательный URL подготовленного JSON рельефа.
environment.ground_height_wgs84_m number; m; idealized Постоянная высота поверхности WGS84, по умолчанию 0. Ветер отсутствует.
monte_carlo.parameters.size.mass_kg number | number[2]; kg; > 0 Начальная масса напрямую: фиксированная или равномерная. Альтернатива диаметру и H/альбедо; ровно один режим size.
monte_carlo.parameters.size.diameter_m number | number[2]; m; > 0 Начальный диаметр: фиксированный или равномерный. Масса πρD³/6. Не вместе с mass_kg или H/альбедо.

Совместимость и импорт

Ниже описаны старые поля и альтернативные формы общего атмосферного импорта. UI-подготовка орбитального handoff требует более строгого формата входов на 100 км.

Поле Тип и допустимые значения Описание
entries[].weight number >= 0; optional Новый орбитальный экспорт не пишет поле; отсутствие равно 1. Старое weight:1 принимается. Общий атмосферный импорт поддерживает неединичные веса при положительной сумме; UI-handoff требует единичные. Не путать с кратностью фрагментов.
manifest.probability_scope string; legacy Старая поясняющая строка о смысле вероятности. Новый экспорт её не пишет; загрузчик не использует.
entries.frame_model string; legacy Старые архивы могут содержать IAU1976/1980 UT1/GAST, no polar motion без профиля EOP. Профиль нельзя достоверно восстановить только по этой строке.
epoch_jd_utc number; JD UTC При общем импорте допустим вместо epoch_mjd_utc, но не вместе с ним. Преобразуется вычитанием 2400000.5.
latitude_deg number; degree Альтернативный геодезический вход: вместе с longitude_deg, height_wgs84_m и velocity_enu_mps вместо пары ECEF-векторов.
longitude_deg number; degree Долгота альтернативного геодезического входа, восток положительный.
height_wgs84_m number; m Высота альтернативного входа над WGS84. Не высота над местной землёй и не ортометрическая высота DEM.
velocity_enu_mps number[3]; m/s Скорость [east,north,up] альтернативного входа; переводится в ECEF. Геодезические и ECEF-поля не смешиваются.
r_itrs / v_itrs / jd_utc number[3] / number[3] / number Старый файл входов без schema_version: положение в м, скорость в м/с, эпоха JD UTC. Принимается общим загрузчиком, но не подготовкой орбитального handoff в UI.
maps.image_width integer; 800 ... 4096; legacy Старая ширина растрового изображения, по умолчанию 1600. Принимается, но текущий HTML-рендер не использует и повторный экспорт не записывает.
maps.font_file string; path; legacy Старый путь к шрифту растра. Принимается, но не используется текущим HTML-рендером и не записывается повторно.
